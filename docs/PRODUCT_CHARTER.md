# 产品章程 PRODUCT CHARTER · jeegit

> 文档状态：v1.0 · 架构宪章级别（3–5 年不轻易变更）

## 1. 愿景

打造一个 **中国本土、面向政府数字化转型、同时适配中小企业刚需** 的
**AI-Native 企业级快速开发平台框架**，以 **纯开源免费** 的方式持续发布，
具备 **未来 20 年的技术竞争力** 与 **社区可持续性**。

## 2. 使命

- 让政企在 **最短路径** 构建 **合规、可审计、可治理** 的数字化应用。
- 让开发者能像搭积木一样，用 **平台内核 + 插件 + 行业模板** 快速交付。
- 让 **AI 能力** 以 **平台一等公民** 的方式被使用、被治理、被替换。

## 3. 目标用户

| 用户           | 诉求                                                                 |
| -------------- | -------------------------------------------------------------------- |
| 政府部门       | 合规审计、跨部门协同、事项受理督办、可国产化/私有化部署              |
| 中小企业       | 低门槛、上手快、二开友好、成本可控、开箱行业模板                     |
| ISV / 集成商   | 插件化架构、可复用业务组件、API/SDK 完整                             |
| 开发者 / 社区  | 代码清晰、文档齐全、贡献路径明确、长期维护承诺                       |

## 4. 边界 — 我们做什么

- ✅ 平台内核：IAM、多租户、审计、权限、API 网关接入、工作流接入点
- ✅ AI 原生底座：模型网关、Agent 运行时、工具注册、RAG、评测、人机协同
- ✅ 四中台能力底座：数据 / 业务 / 技术 / 应用
- ✅ 开放平台：API 网关接入、开发者门户骨架、API 资产目录
- ✅ 行业模板：事项受理审批、工单协同督办（首批政企共用刚需场景）
- ✅ 治理文档：模型/数据/安全/合规策略

## 5. 边界 — 我们不做什么

- ❌ **不做** 大而全低代码平台（不追求"万能拖拽"）
- ❌ **不做** 单一大模型厂商 SDK 的薄封装
- ❌ **不做** 闭源商业版 / 核心功能阉割
- ❌ **不做** 一次性"交付即完"的项目式代码

## 6. 成功标准（长期）

| 维度       | 成熟期目标                                                    |
| ---------- | ------------------------------------------------------------- |
| 代码       | 100 % Apache-2.0 开源，核心能力不阉割                          |
| 用于生产   | 有真实政企生产环境采用（而非仅 Demo）                          |
| 社区       | 多厂商贡献者、插件市场、行业模板持续产出                       |
| 治理       | 有独立 RFC 流程 / Maintainer 机制 / 版本承诺                   |
| AI 竞争力  | 模型、向量库、Agent 编排框架可随时替换，无供应商锁定           |

## 7. 商业可持续（不卖授权）

代码免费，**服务 / 实施 / 培训 / 托管 / 行业共建** 付费。

## 8. 不可变承诺（写死）

1. License：**Apache-2.0**，不切换。
2. 核心能力：**不阉割**，不分"社区版/企业版"。
3. API 兼容：**主版本内不破坏**，弃用需公告过渡期。
4. 治理：**RFC + DCO/CLA + 公开 Roadmap**。
