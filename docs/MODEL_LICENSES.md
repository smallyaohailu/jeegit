# 模型许可政策 MODEL_LICENSES · jeegit

jeegit 本身以 **Apache-2.0** 发布。模型许可与代码许可是两件事，本文档列出平台默认的模型选择策略。

## 策略

1. 平台**不内置**任何有商用限制的模型权重。
2. 集成的任何模型由 **运行方自行评估** 其许可条款与合规风险。
3. 推荐优先级：
   - **本地部署的开源可商用模型**（如 Llama 系列、Qwen 开源可商用档位、Gemma 等，按其各自条款）
   - **OpenAI 兼容 API**（由客户自行采购）
   - **其他云厂商 API**

## 平台要求

- 所有模型调用统一走 `ModelGateway`，不允许旁路调用。
- 不同租户可配置不同模型提供商与权重，默认最小权限。
- 切换模型**不应**要求业务代码改动。

## 免责声明

平台代码按 Apache-2.0 提供。第三方模型权重的许可责任由使用者自行承担。
