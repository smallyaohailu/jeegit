# Product practice (Google-aligned)

jeegit's product practice mirrors the methodology Google's teams publicly describe:

- **PRDs** socialise a problem before engineering commits (ex-Google PMs' *Product Requirements
  Document* pattern).
- **OKRs** ([re:Work by Google](https://rework.withgoogle.com/guides/set-goals-with-okrs/))
  give direction at the quarter + annual cadence without dictating the path.
- **Launch checklists** (the "LCR" — Launch Coordination Review — adapted from *Site Reliability
  Engineering* ch. 27) gate a release against reliability, privacy, legal, and i18n concerns.
- **Dogfooding** and **fishfooding** precede external availability.
