# AI 安全策略 AI_SAFETY_POLICY · jeegit

## 1. 威胁模型

- **Prompt Injection**：通过用户输入/文档内容注入指令操纵 Agent。
- **工具滥用**：Agent 调用未授权工具或逾越权限范围。
- **数据外泄**：通过模型输出间接泄漏敏感数据。
- **幻觉**：模型虚构事实造成决策失误。
- **对抗输入**：针对 RAG / 分类器的数据投毒。

## 2. 防护措施（平台默认启用）

1. **Agent 权限最小化**：默认无任何工具；工具白名单显式授予。
2. **工具沙箱**：工具调用经 Runtime 统一校验参数、限流、审计。
3. **Prompt 加固**：系统指令不可覆盖；用户输入作为"数据"而非"指令"拼入。
4. **输入/输出过滤**：敏感信息（PII、密钥、内部 URL）正则 + 模型双层过滤。
5. **高风险动作 HITL 阻塞**：无人工审批不得执行。
6. **评测门禁**：变更必须通过评测集才能发布。
7. **可回滚**：任意 Agent/Prompt/模型配置可一键回到上一稳定版本。

## 3. 事件响应

- 发现疑似 Prompt Injection → 立即封禁对应输入源 + 审计回溯。
- 发现工具滥用 → Runtime 立即撤销 Agent 的相关工具权限。
- 发现数据外泄 → 触发事件流停机 + 取证。

## 4. 政务场景特殊要求

- 对外通知类动作 **全部** 归为 HIGH 风险，必须 HITL。
- 涉及法规判断的问答必须附带 **引用来源**；无引用不得下发结论。
