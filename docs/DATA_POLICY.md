# 数据政策 DATA_POLICY · jeegit

## 基本原则

1. **数据主权归属使用方**。平台不持有、不回传任何运行时数据。
2. 默认 **本地/私有化部署**，不依赖联网。
3. 敏感数据在日志、审计、Prompt 中强制脱敏。
4. 跨租户访问默认禁止；跨境数据流转默认禁止。

## 数据分类

| 级别 | 示例                                   | 默认策略                       |
| ---- | -------------------------------------- | ------------------------------ |
| L0   | 公开信息（政策文本、公开政务数据）     | 可用于所有场景                 |
| L1   | 内部运营数据（工单、统计）             | 租户内可用                     |
| L2   | 个人信息（姓名、联系方式）             | 必须脱敏、必须审计             |
| L3   | 敏感个人信息（身份证、生物特征）       | 默认禁用于 LLM，需策略显式放行 |

## 数据使用到 AI 的原则

- L3 数据**默认禁止**参与模型调用 / RAG 索引。
- L2 数据进入模型调用前必须走脱敏策略。
- 所有进入 ModelGateway 的 Prompt 需审计（哈希存储，可选留原文）。

## 数据生命周期

- 日志与审计：仅追加、最短保留期由运营方设定（默认 180 天）。
- 训练数据：如需本地微调，**必须**经数据所有方显式授权。
